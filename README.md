## Chart File Naming

Every chart name includes its model count and its size range (height x width):

```
{models count}_{height}x{width}.txt
```

**Example:** `279_164x75.txt`

| Part  | Meaning                                    |
|-------|--------------------------------------------|
| `279` | Number of models in the chart              |
| `164` | Height range (H): 164.00 to 164.99 mm      |
| `75`  | Width range (W): 75.00 to 75.99 mm         |

The file name shows the whole-number range, not the exact size. For example, a chart named `173x78` holds every phone from 173.00 to 173.99 mm tall and from 78.00 to 78.99 mm wide.

## Chart Format

Each chart lists one phone per line, in the format `Brand Model` followed by its size (height X width, in mm).

Phones are split into groups by a blank line:

1. **Exact-size groups.** Phones with exactly the same size sit together. Each group is separated from the next by a blank line.
2. **Same-range group (last).** Phones that fall in the same range but do not have an exact match come last, one per line, with no blank lines between them.

## How to Find Phones With the Same Case and Tempered Glass

1. Find your Phones,Tablets,Watch brand and model.
2. Open the chart file that contains it. The file name shows the number of models and the size range, for example `279_164x75.txt`.
3. Look at the group your phone is in:
   - **Exact-size group:** every phone in the same group has exactly the same size as yours.
   - **Same-range group:** the sizes are close but not identical, so check the exact sizes before buying shared stock.
4. Use the list to buy one stock item that fits all phones in your group instead of one item per model.

## FAQ

### Which Phones,Tablets,Watch use the same case?

Phones listed in the same exact-size group have identical dimensions, so they are the best candidates for sharing the same case.

### Which Phones,Tablets,Watch use the same tempered glass screen protector?

Use the same method: find your phone in its chart, then check the phones in its exact-size group. Phones in the same range but with different exact sizes may need a different screen protector.

### What does the number in the file name mean?

The first number is how many phone models are in the chart. The two numbers after it are the height and width range in millimeters, for example `279_164x75.txt`.

### How do I avoid dead stock when buying phone accessories?

Buy by size group instead of by model. One item that fits every phone in a group sells more easily than many items that each fit a single model.

### Are the sizes in millimeters?

Yes. All sizes are given as height X width in millimeters.
